# design/mock — CMS 抜きの HTML モック（一回転目）

トップ・記事詳細・タグ別一覧の 3 ページを、HTML と CSS 1 枚だけで組んだもの。承認した版は、CMS に移した後の見た目の比較基準と、作り直しの固定課題になる。

- JavaScript・Web フォント・外部への参照は無い（`grep -rn "http" design/mock/*.html design/mock/style.css` が空）
- 外部のデザインは参照していない。素のベースライン
- 記事・出典・告知の文はすべて架空。自己紹介・告知・サイトの一言は、枠の役目を書いた仮の文

## 見方

```sh
python3 -m http.server -d design/mock 8787
```

ブラウザで `http://localhost:8787/` を開く。止めるのは Ctrl+C。ファイルを直に開いてもよい（`index.html` をブラウザに落とす）。

幅は 2 つで見る：デスクトップ（1280px 前後）とモバイル（390px 前後。開発者ツールの端末表示）。CSS の切り替えは 768px と 540px。

| ファイル | 中身 |
|---|---|
| `index.html` | トップ。ヘッダー・告知バナー・自己紹介枠・記事カード 7 本・フッター |
| `article.html` | 記事詳細（記事 a1）。見出し・副題・日付・タグ・要約・本文の 4 ブロック・出典一覧・関連記事 3 本 |
| `tag.html` | タグ別一覧（タグ「運用」）。タグ名・本数・カード 4 本 |

各部位の要素に `data-part` を付けた。下の表の「部位」と同じ名前で、1b で Astro の部品と CMS の欄に移すときの目印にする。

## 導出表との対応（統合構想書 4.5）

| HTML で観測した要素 | このモックのどこか | 導出を検討する CMS 側の構造 |
|---|---|---|
| 記事カードの繰り返し | トップの `article-list`（7 枚）・タグ別一覧（4 枚）・関連記事（3 枚）。カードの形は 1 つ（`article-card`） | 記事の collection（題・副題・日付・画像・タグ） |
| カテゴリ別一覧 | `tag.html` 全体（タグ「運用」で絞った一覧） | タグの taxonomy と、タグで絞る一覧の取得 |
| 共通ヘッダー・フッター | 3 ページの `site-header`・`site-footer` | Astro の共通レイアウト（今の `src/layouts/Base.astro`） |
| 特集枠（自己紹介枠で代替） | トップの `intro` | 固定の 1 枠。サイトの設定か、1 件だけのページ |
| 関連記事 | 記事詳細の `related`（3 枚） | 記事どうしの関係（同じタグから選ぶか、手で選ぶか） |
| タグ・検索・フィルタ（タグだけ） | カードと記事の見出しの下のタグ。押すとタグ別一覧 | タグの taxonomy の一覧取得。検索とフィルタは一回転目では作らない |
| ページごとの異なる表示 | トップ（告知・自己紹介あり）・タグ別一覧（頭だけ足す）・記事詳細（本文の 4 ブロック・出典） | ページの型ごとのテンプレート |
| 更新される告知・バナー | トップの `notice` | 期限つきで出し入れする編集単位と、公開の制御 |

## 決めたこと

- ナビは今の gikou.dev（トップ・手がけているもの）の後ろに「記事」を足した。記事の一覧ページはモックに無いので、「記事」はトップの記事の並び（`index.html#articles`）へ飛ぶ。フッターも同じ並びに「記事」を足した
- モックに無いページ（手がけているもの・プライバシーポリシー）へのリンクは `#`。フッターの「EmDash で動いています」はリンクにしない（外への参照を 0 にするため）
- 色と書体の値は press の `tokens.css` から、余白と文字の段は今の gikou.dev から取り、`style.css` の頭に元の変数名を添えて書いた。書体は読み込まず、tokens の並び（IBM Plex Sans JP → Hiragino Sans → Noto Sans JP）を手元にある字で組む
- 本文の 4 ブロックの見た目：
  - 原文は引用の形（`blockquote`・英語）で、出典の分類の色（公式＝橙・非公式＝緑）の帯と地色。訳は同じ箱の下に点線で区切って添える
  - 要約は、引く出典の分類の色の帯で、地は白。原文の箱と地色で見分ける
  - 見解は GIKOU の青で、帯を太くする
  - 各ブロックの右上に出典番号。押すと出典一覧の行へ飛び、その行に色が付く
  - ラベルは press の 4 種（原文・翻訳・自動生成・要約・自動生成・自動生成（GIKOU Media））
- 記事の頭の要約は、複数の分類の出典にまたがるので、色を付けず無彩色の地にした
- 出典番号は 1 から振る（編集パイプラインの記事は 0 から。1b の変換で 1 を足す）
- 出典一覧には原典の URL を出さず「原典の場所は CMS が持つ」と書いた。CMS では出典の行から原典へリンクする
- 記事の題は `title`、副題は `headline` に当たる
- 記事詳細とタグ別一覧はそれぞれ 1 枚だけ。どのカードを押しても `article.html`（a1）へ、どのタグを押しても `tag.html`（運用）へ飛ぶ
- カードの画像は 16:9 に切って並べ、画像の無いカードは上に青い細い帯を置く。副題は 3 行で切る
- フッターに、press の design の注意書き（R-WEB-2）の日本語の 2 文を置いた
